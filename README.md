## 🏛️ Introduction

Welcome to **Taska**, your go-to Flutter application for effective task management. Taska is designed to streamline your daily activities, boost productivity, and empower you to achieve your goals efficiently. Whether you're a professional looking to organize work tasks or an individual seeking a tool to manage personal responsibilities, Taska has got you covered.

Built with modern Flutter architecture and best practices, Taska offers a seamless experience across all your devices. With powerful features like local notifications, focus mode, and smart categorization, managing your tasks has never been easier or more enjoyable.

---

## 🚀 Features

### 📋 Task Management
- ✅ **Create & Organize Tasks** - Add tasks with titles, descriptions, and deadlines
- 📅 **Calendar Integration** - Visualize tasks on an intuitive calendar view
- 🎨 **Custom Categories** - Create and manage personalized task categories with custom colors
- ⚡ **Priority Levels** - Assign priority levels to focus on what matters most
- 🔔 **Smart Notifications** - Get reminded of important tasks at the right time
- 📝 **Quick Edit** - Easily update task details on the go

### 🎯 Productivity Tools
- ⏰ **Focus Mode** - Dedicated timer to help you concentrate on tasks
- 📊 **App Usage Tracking** - Monitor your productivity patterns
- 📈 **Task Statistics** - View insights about your task completion rates
- 🗓️ **Monthly Overview** - Get a bird's-eye view of your monthly tasks
- ✨ **Task Completion** - Mark tasks as complete with satisfying animations

### 👤 User Experience
- 🔐 **Secure Authentication** - Firebase email/password and Google sign-in
- 🌓 **Dual Themes** - Beautiful light ☀️ and dark 🌙 mode support
- 🌍 **Multi-Language Support** - Available in 7 languages (English, Arabic, French, Spanish, German, Italian, Portuguese)
- 📱 **Responsive Design** - Optimized for all screen sizes
- 🎨 **Beautiful UI/UX** - Modern, clean interface with smooth animations
- 💾 **Offline Support** - Work seamlessly without internet connection

### 🔔 Smart Features
- 🔕 **Do Not Disturb** - Automatic DND mode during focus sessions
- 📸 **Profile Customization** - Upload and manage your profile picture
- 🎯 **Task Filtering** - Filter tasks by category, priority, or date
- 🔄 **Real-time Sync** - Cloud sync across all your devices
- 💫 **Smooth Animations** - Delightful transitions and interactions

## 🔧 Installation

### Prerequisites
- Flutter SDK (3.9.2 or higher)
- Dart SDK
- Android Studio / VS Code with Flutter plugin
- Firebase project
- Physical device or emulator

### Quick Start

1. **Clone the Repository**
   ```bash
   git clone https://github.com/sayedmostaf/taska.git
   cd taska
   ```

2. **Install Dependencies**
   ```bash
   flutter pub get
   ```

3. **Firebase Configuration**
   - Create a Firebase project
   - Add `google-services.json` to `android/app/`
   - Add `GoogleService-Info.plist` to `ios/Runner/`
   - Enable Authentication (Email/Password)
   - Set up Cloud Firestore

4. **Run the App**
   ```bash
   flutter run
   ```

```
│
├── 📁 features/
│   ├── auth/
│   │   ├── data/
│   │   │   ├── datasources/   # Remote (Firebase) and local data sources
│   │   │   ├── models/        # User and auth models
│   │   │   └── repos/  # Auth repository implementations
│   │   ├── domain/
│   │   │   ├── entities/      # Core entities
│   │   │   ├── repos/  # Repository contracts
│   │   │   └── usecases/      # Business logic (login, register, etc.)
│   │   └── presentation/
│   │       ├── managers/          # BLoC/Cubit for state management
│   │       ├── views/         # Auth screens
│   │       └── widgets/       # Auth-specific widgets
│   │
│   ├── calendar/              # Calendar feature
│   ├── focus/                 # Focus mode feature
│   ├── home/                 # Task management feature
│   ├── index/               # Index feature

│   └── splash/            # Splash screen
│
├── firebase_options.dart      # Firebase configuration
└── main.dart   # App entry point
```

- **flutter_screenutil** - Responsive UI scaling across devices
- **motion_toast** - Animated toast notifications
- **app_usage** - Track app usage statistics
- **do_not_disturb** - Control DND settings programmatically
